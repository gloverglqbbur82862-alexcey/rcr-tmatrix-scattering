# Figure Manifest for JQSRT / Optics Express Validation Package

This folder contains manuscript-ready figures generated from the RCR simulation results.

## Figures List

### 1. Figure 1: MSTM Parity Summary
- **File**: `fig1_mstm_parity_summary.png`
- **Caption**: Parity verification of the analytical orientation-averaged extinction efficiency $Q_{\text{ext}}$ between the Python RCR engine and MSTM v4.0 across aggregate sizes $N = 4$ to $128$ for a BCCA soot aggregate cluster ($r = 25$ nm, $\lambda = 550$ nm, $m = 1.95 + 0.79i$). Left: Parity scatter plot matching the 1:1 line. Right: Relative error vs. number of monomers $N$, showing agreement to within $0.002\%$.

### 2. Figure 2: Mueller Matrix Wavelength Sensitivity
- **File**: `fig2_bcca_bpca_mueller_wavelengths.png`
- **Caption**: Comparison of the orientation-averaged Mueller matrix components $F_{11}(\theta)$, $F_{12}(\theta)/F_{11}(\theta)$, $F_{33}(\theta)/F_{11}(\theta)$, and $F_{34}(\theta)/F_{11}(\theta)$ over $0..180^\circ$ scattering angles for BCCA (solid lines) and BPCA (dashed lines) soot aggregate clusters ($N=16$) at wavelengths $\lambda = 450$ nm (blue), $550$ nm (green), and $650$ nm (red). Showcases morphology and spectral sensitivity.

### 3. Figure 3: Morphological Size Scaling
- **File**: `fig3_size_scaling_metrics.png`
- **Caption**: Scaling behavior of global optical metrics ($Q_{\text{ext}}$, $Q_{\text{sca}}$, Single Scattering Albedo SSA, and asymmetry parameter $g$) as a function of the monomer count $N \in \{8, 16, 32, 64\}$ at $\lambda = 550$ nm. Compares the fractal compactness profiles of BCCA (blue circles) and BPCA (red squares) clusters.
