# Application results

The paper's ensemble results are stored in `results/seed0-9/`. This directory
contains the formal BCCA/BPCA calculations for independent random seeds 0
through 9. It is the input directory for ensemble tables and manuscript
figures.

The parent `results/` directory may contain seed-42 demonstration results and
new results generated by `run_batch.py`; these are not part of the formal
ten-realization ensemble unless they are explicitly selected.

## Reproduce the reported ensemble

From the repository root:

```powershell
python scripts/reproduce_figures.py
```

This reads `experiments/application/results/seed0-9/`, writes summary tables
to `data/results/`, and writes generated figures to `figures/generated/`.

To generate additional cases, use `run_batch.py`. Its newly generated output
is written to the parent `results/` directory; move or copy a complete,
audited seed ensemble into a separately named subdirectory such as
`results/seed0-9/` before using it as manuscript input.
